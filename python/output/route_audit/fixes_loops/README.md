## Notes

- #42 is the same Purwosari trail as #25 (100% of #42 within 30 m of #25); #25 starts ~2.6 km lower at the Tambak Watu basecamp, #42 starts where OSM's 'via Purwosari' way begins (1195 m). Consider merging or dropping #42 as a near-duplicate.
- #51 visits both summits; the kept track is the recording's own order Cibodas -> Pangrango -> Kandang Badak -> Gede, so the Kandang Badak <-> Pangrango spur (~2 km) appears twice. For a pure one-way to Pangrango only, cut at Pangrango (8.6 km 2D).
- #79 Wilis and #119 Rakutak: the OSM named way/relation covers both trails of the loop, so OSM does not tell which side is the main trail; rule (c) kept the uploader's start.
- #72 and #76: the OSM hiking relations named after the basecamp map the whole loop (both halves), so the decision uses the individually named ways.
- #31: the old 9.47 km was inflated by every point being stored twice (gpxpy smoothing on duplicates adds vertical zig-zag); the dropped start is a flat 0.6 km (751-761 m) incl. the 504 m straight line.
- #25: points unchanged, only the 6 <trk> merged into one (km unchanged within rounding).
- #110 Panderman needs no fix (identical to OSM 'Jalur pendakian Gunung Panderman'); plan action 'keep', no GPX written. It starts at 1600 m, part-way up; only an extension could change that.
